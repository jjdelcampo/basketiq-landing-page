Proprietary · First in Europe

Basketball Ontology

A structured semantic map of 2,000+ formative basketball concepts — the foundation nothing else has.

  • OWL/RDF schema: exercises, progressions, objectives, age groups
  • Example: "Suspension shot" → 8-stage progression → 50 drills → common errors
  • Knowledge Graph (Neo4j) — queryable, extensible, club-specific adaptable
  • Built from FIBA, WABC, FEB official sources — fully auditable
⚡
GDPR-Compliant · Zero Hallucinations

RAG + Citation Lineage

Orchestration layer that leverages **Claude, GPT, and Gemini** through a sovereign enterprise gateway.

  • Multi-model routing: optimized for response cost vs accuracy
  • SOC2/GDPR compliant infrastructure (AWS Bedrock / Vertex AI)
  • Citation lineage: automatic source verification for every response
  • NLU Precision: high-accuracy basketball domain understanding
💬
Zero Friction · Zero App

WhatsApp-First UX

Coaches already live on WhatsApp. We don't ask them to change behavior.

  • Conversational: ask, refine, drill down — just like texting an expert
  • Response time: <30 seconds for structured, cited answer
  • Context memory: follow-up questions build on previous exchange
  • Future: Web portal + analytics dashboard for club coordinators
🔄
Adaptive · Club-Specific

Living Knowledge Graph

The KB is not static. Every session, every coach interaction, every match outcome teaches the system.

  • Confidence scores on every relationship — exercises that get used go up; rejected ones go down
  • Nightly ETL: WhatsApp session logs → graph confidence updates (automated)
  • Coach retrospectives + match analysis feed back into the graph
  • Club-specific layer: your club's patterns personalize your recommendations over time
  • Future: multi-club consensus — Bayesian averaging across clubs improves the shared graph for everyone
